# 🌐 LingoMate MK2

> A production-grade language exchange platform built with React, Node.js, Socket.IO, WebRTC, PostgreSQL, and Gemini AI.

### 🚀 Key Highlights

- 💬 Real-time messaging powered by Socket.IO
- 🌐 AI-powered multilingual conversations
- 📞 Peer-to-peer video calling with WebRTC
- 🔄 Three translation modes (Bridge, Comfort, Learning)
- 📚 Persistent conversation history and call logs
- ⚡ Production deployment on Render + Neon

### 🔗 Live Demo

https://lingomate-mk2.onrender.com

### 🛠 Tech Stack

React • Vite • TanStack Query • Node.js • Express • Socket.IO • WebRTC • PostgreSQL • Prisma • Cloudinary • Gemini AI
